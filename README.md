# Programming for AI - Assignment 3

## Overview
This repository contains the completed Assignment 3 for Programming for AI.

## Project Structure
- `data/` - Provided CSV and NumPy datasets.
- `outputs/` - Generated dashboard images, PDF, and GIF.
- `Assignment3_Programming_for_AI.ipynb` - Main assignment notebook.

## How to Run
1. Install Python and Jupyter Notebook.
2. Open the notebook in VS Code or Jupyter.
3. Make sure the `data/` folder is in the same directory.
4. Run all cells in order to generate the outputs.

## Challenge
One challenging part was creating the dashboard visualizations and exporting them into different file formats.
